# Mosaica — Questionário de Perfil Comportamental

O questionário que as pessoas respondem, publicado para abrir em qualquer
navegador, sem conta e sem instalação:

**https://flaribes-cmd.github.io/mosaica/**

## O que tem aqui

Só o questionário. Ele não mostra relatório nenhum: no fim gera um código
que a pessoa envia para quem a convidou. O relatório é montado pelo mentor,
noutro aplicativo, e entregue numa conversa de devolutiva.

## O que não passa por aqui

Nenhuma resposta. Elas ficam no navegador de quem responde e viajam só
dentro do código que a própria pessoa copia e envia. Este repositório
serve um arquivo em branco.

## Endereço anterior

Este repositório chamava-se `misapin`, nome do programa de mentoria que
deu origem ao produto. O GitHub redireciona o endereço antigo, então
convites já enviados continuam funcionando.
